# Hayder & Husna — Digital Wedding Invitation

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — countdown, RSVP WhatsApp button and share button
- `invitation-card.png` — original invitation artwork

## Customize before publishing
1. Open `script.js`.
2. Replace `251900000000` with the family's real WhatsApp number.
3. In `index.html`, replace the Google Maps search URL with the exact venue location if available.
4. Upload the whole folder to your hosting provider.

The invitation date is set to August 30, 2026 at 6:00 PM East Africa Time.
