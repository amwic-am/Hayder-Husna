## Customize Before Publishing

### 1. WhatsApp RSVP Number

Open:

script.js

Find:

251900000000

Replace it with the family's real WhatsApp number.

Use international format without:

- +
- spaces
- leading 0

Example:

2519XXXXXXXX

========================================

script.js

The website is a static website and can be hosted on:

- Vercel
- Netlify
- GitHub Pages
- cPanel Hosting
- Any standard web hosting

========================================

## Important

For the Get Directions feature to access the guest's current location, the website should be served through HTTPS.

Location permission is controlled by the guest's browser.

If the guest denies location permission, Google Maps will still open and allow them to select their starting location.
